- ETL Survey — SQL Server + SSIS

Academic project for implementing **ETL (Extract, Transform, Load)** 
processes using **SQL Server cursors** and **SSIS packages** to move 
data from Excel into a relational model and, subsequently, into a 
multidimensional model.


- Objective

Implement **Extract, Transform, Load (ETL)** processes using SQL Server 
cursors and SSIS components, applying data quality treatments to move 
information from Excel into a relational model and, subsequently, into 
a multidimensional model.
